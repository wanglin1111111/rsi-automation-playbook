# 验证层级：环路天花板 = 替代信号的质量

每一条自我改进环路，本质都是**"某个信号可以替代人类判断"的声明**。环路天花板就是该替代品的质量。

## 四层（从高到低：越往上越可靠但覆盖面越窄，越往下越便宜但越容易被钻空子）

| 层 | 验证信号 | 可靠性 | 覆盖面 | 典型形态 |
|---|---|---|---|---|
| 1 | 形式化验证器 | 最高 | 最窄 | 数学证明、类型检查、形式化模型检验 |
| 2 | 执行反馈 | 高 | 较宽 | 能跑的测试、能对账的数据、能查的格式 |
| 3 | 学习型裁判 | 中 | 宽 | LLM 评审（含 LLM-as-judge） |
| 4 | 内在信号 | 最低 | 最宽 | 模型自评/自述 |

## 核心规则：验收方式决定能自动化到哪一层

- **1-2 层（机器客观验收）**：放心交给 Agent 闭环（AL4+）
- **3-4 层（"感觉写得不错"）**：必须留人在环上（封顶 AL3）
- **用第三层工具解决第四层问题 = 范畴错误**（见下方失败模式）

## 失败模式解释（为什么有的成功有的翻车）

| 案例 | 原因 |
|---|---|
| FunSearch / AlphaEvolve 成功 | 站在验证层级顶端：程序可执行、结果可检验（第 2 层执行反馈） |
| "AI 科学家"系统产出流畅却难以审计的论文 | 用第三层工具（LLM 裁判）解决第四层问题（研究品味）——裁判本身比被裁判的问题低一层 |

## 有界 vs 开放 RSI（arXiv:2607.07663 综述，梳理 2024-2026 年 1,250 篇论文）

| | 有界自我改进 | 开放式 RSI |
|---|---|---|
| 标准 | 针对固定外部标准 | 连改进标准本身也被改写 |
| 收敛性 | 可收敛 | 原则上发散 |
| 现状 | 已是工业实践 | 无工业实例 |

- 26% AL4 = 典型的"人在环上"，正是当前文献主体所在
- RSI 相关 arXiv 论文 2026Q2 单季 501 篇：部署时自我演化 393 / 训练时自我迭代 340 / 自我评估 318（2026 年增长最快）/ 自动研究 139
- **领域指数膨胀 ≠ 开放 RSI 到来**：自我评估增长最快恰恰说明"谁来验证"仍是瓶颈
